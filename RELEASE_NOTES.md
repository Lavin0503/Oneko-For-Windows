# Oneko for Windows v2.0

**A tiny pixel cat that chases your mouse around your Windows desktop. Click-through, customizable, and one small .exe.**

### What's new
- 🎨 Brand-new animated settings window with tabs, sliders and a live cat preview
- 💻 **Terminal Version:** the cat pixelates when she walks over a terminal
- 🌈 7 cat colors, opacity, sprint mode and more customization
- 🐾 Default cat size is now 2x
- 🖱️ Click-through: she never blocks your clicks
- 🔁 Launching Oneko again opens the settings window instead of an error

### Install
Download **Oneko.exe** below and double-click it. If SmartScreen warns about an unknown publisher, click *More info → Run anyway*. Find the cat in the system tray to open settings or quit.
